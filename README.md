# 🐄 DairyCare — Smart Cow Management System

DairyCare is a full-stack Flask application designed to manage dairy farm records, vaccination history, and artificial insemination schedules with automatic gestation period calculations.

## ✨ Key Features
* 🤰 **Gestation Tracking:** Auto-calculates calving dates based on 279-day (9 months 9 days) cycles.
* 📱 **Authentication:** OTP-based login system for farmers.
* 🌐 **Multi-language Support:** English & Marathi dynamic interface.
* 📋 **Livestock Management:** Full CRUD tracking for registered cows.

## 🛠️ Tech Stack
* **Backend:** Python (Flask), SQLite
* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting:** PythonAnywhere
